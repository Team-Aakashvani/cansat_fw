1. SHARED I2C SENSOR BUS ARCHITECTURE
--------------------------------------------------------------------------------
All four primary environmental and navigation sensors share a common 2-wire
I2C bus with common 3.3V power and ground rails.

Bus Configuration:
  • Microcontroller Port: I2C_NUM_0
  • SDA Pin:              GPIO 38 (Internal Pull-Up Enabled + Sensor Board Pull-Ups)
  • SCL Pin:              GPIO 39 (Internal Pull-Up Enabled + Sensor Board Pull-Ups)
  • Clock Frequency:      25 kHz (Slow, highly stable rate immune to cable capacitance
                          and multi-drop fly-wire ringing)

Common Power Rails:
  • 3.3V (VCC / VIN):     Pin labeled "3V3" on ESP32-S3-DevKitC-1
  • GND:                  Pin labeled "GND" on ESP32-S3-DevKitC-1

4. CALIBRATION & TRANSFER FUNCTIONS IN FIRMWARE
--------------------------------------------------------------------------------

A. IMU Attitude:
   • Internal BSX fusion chip calculates absolute quaternion / Euler angles.
   • Firmware uses hardware tare calibration with zero angular drift at rest.

B. BMP585 Barometric Altitude:
   • Hypsometric barometric equation:
     h = 44330.0 * (1.0 - (P / P0)^(1.0 / 5.255))
   • P0 automatically baseline-calibrated on boot across 20 samples to 0.00 m AGL.

C. SHT4x Temperature & Humidity:
   • T [°C]  = -45.0 + 175.0 * (S_T / 65535.0)
   • RH [%]  = -6.0 + 125.0 * (S_RH / 65535.0)
   • Full Sensirion CRC-8 polynomial (0x31, init 0xFF) error checking.

D. SGP41 Gas Index Models:
   • VOC Index = 100.0 * (S_raw / S_base)^(-2.5), clamped to [1, 500].
     - Clean ambient baseline = 100 (Green).
     - Aerosols / room fresheners / solvents spike > 100 (Yellow / Orange / Red).
   • NOx Index = 1.0 + 499.0 * (1.0 - exp(-5.0 * (S_raw / S_base - 1.0))), clamped [1, 500].
     - Clean ambient baseline = 1 (Green).
